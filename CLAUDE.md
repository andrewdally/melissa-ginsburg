# Working on this repo

## Branch names

Name branches for what they change, in the form `<type>/<short-description>`:
lower case, words separated by hyphens, a few words long.

- `feat/…` for new features: `feat/pages-cms`, `feat/design-round-4`
- `fix/…` for fixes: `fix/design-review-1`
- `docs/…` for README and other docs only

Don't use generated names like `claude/intelligent-dirac-0lb8fw`. If a session
is handed one, do the work on a branch named as above instead, and say so.
